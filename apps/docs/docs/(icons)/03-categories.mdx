Every Vadivam icon has one name, a set of tags, and one or more categories. The names and metadata come from the pinned [Lucide](https://lucide.dev) release, so each icon has the name it has in Lucide.

## Names

An icon's name is lowercase kebab-case, such as `arrow-right` or `circle-exclamation-point`. Each package derives its own form from that name:

| Where | Form | Example |
| --- | --- | --- |
| SVG file and URL | kebab-case | `circle-exclamation-point.svg`, `/icons/circle-exclamation-point` |
| Component import | PascalCase | `import { CircleExclamationPoint } from "vadivam-react"` |
| Per-icon import | kebab-case path | `vadivam-react/circle-exclamation-point` |
| Dynamic APIs and `iconNames` | kebab-case | `<DynamicIcon name="circle-exclamation-point" />` |
| shadcn/ui registry | kebab-case | `/r/circle-exclamation-point.json` |
| Flutter | lowerCamelCase | `VadivamIcons.circleExclamationPoint` |
| Jetpack Compose | PascalCase | `VadivamIcons.CircleExclamationPoint` |
| Android drawable | snake_case | `R.drawable.vadivam_circle_exclamation_point` |

Each name is a current canonical Lucide name. Older Lucide names and aliases, such as `alert-circle` for `circle-exclamation-point`, `home` for `house`, or `bold` for `letter-b`, are not separate icons. The [Lucide codemod](/docs/migrate-from-lucide) and the [Figma plugin](/docs/figma-plugin) map them to the current name.

## Tags

Tags are search synonyms. `activity` is also found by "pulse", "heart rate monitor", and more. The [icon catalog](/), the [Figma plugin](/docs/figma-plugin), and the [MCP server](/docs/mcp) all search tags, and `vadivam/manifest` exports them for your own search:

```js
import { icons } from "vadivam/manifest";

const matches = icons.filter((icon) => icon.tags.includes("pulse"));
```
