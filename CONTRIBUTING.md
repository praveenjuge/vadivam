# Contributing to Vadivam

The contributing guide lives in the docs: [vadivam.praveenjuge.com/docs/contributing](https://vadivam.praveenjuge.com/docs/contributing). It covers requirements, setup, adding or updating icons, and the checks to run before a pull request. Draw icons to the [design guide](https://vadivam.praveenjuge.com/docs/design-guide).

```sh
bun install
bun run dev   # docs at http://localhost:4321
bun run test  # before opening a pull request
```
